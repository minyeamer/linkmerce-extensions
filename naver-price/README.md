# 네이버 가격 검증

> 네이버 스마트스토어·브랜드스토어 상품의 실제 가격과 상세페이지 이미지 가격을 비교하는 Chrome 확장 프로그램

네이버 가격 검증은 로그인된 Chrome에서 상품 페이지를 열어 실제 최대 할인가를 확인하고, 커머스API로 가져온 상세페이지 이미지의 가격 표기와 비교합니다. 가격이 다르면 Slack으로 알리고 실행 결과를 CSV로 저장합니다.

## 주요 기능

- 상품 상세 URL을 여러 개 입력해 순차 검증
- 로그인된 사용자에게 표시되는 최대 할인가 확인
- 커머스API 기반 정상가·일반 할인가 확인
- Google Gemini 또는 OpenAI Vision을 이용한 상세페이지 가격 이미지 분석
- 가격 불일치 Slack 알림 및 이미지 미리보기
- 실행 결과 CSV 다운로드
- 매일 지정 시각 자동 실행
- 설정 자동 저장 및 JSON 설정 내보내기·불러오기

## 가격 확인 기준

### 실제 상품 가격

상품 페이지를 먼저 방문해 화면 가격을 읽습니다.

- 최대 할인가: 상품 메인 가격 영역의 최대 할인가 선택자에서 읽습니다.
- 정상가와 할인가: 커머스API 상품 조회가 가능하면 API 응답의 판매가와 원화 즉시 할인액을 사용합니다.
- 커머스API 응답에 정확한 원화 할인액이 없거나 상품 조회 권한이 없으면, 페이지 화면에서 읽은 정상가·할인가를 유지합니다.

커머스API를 조회하지 못하는 상품도 오류로 중단하지 않습니다. 화면에서 확인한 가격만 CSV에 기록하고 다음 상품으로 진행합니다.

### 상세페이지 이미지 가격

생성형AI API 키가 설정되어 있으면 커머스API의 상세 HTML에서 이미지 URL을 수집한 뒤 위에서부터 한 장씩 분석합니다. 제공자에서 Google Gemini 또는 OpenAI를 선택할 수 있습니다.

- 정상가와 가격이 함께 있는 이미지만 가격 이미지로 인정합니다.
- 한 이미지에 여러 옵션·용량 가격표가 있으면 가장 위 가격 블록만 읽습니다.
- 일반 할인가, 쿠폰 할인액, 쿠폰 적용 후 최종 금액을 구분합니다.
- 최종 금액은 최대 할인가, 쿠폰적용 시, 최종 혜택가 등 어떤 문구로 표시되어도 읽도록 요청합니다.
- 가격 이미지를 찾으면 이후 이미지 분석을 중단합니다.

생성형AI API 키를 비워두면 이미지 분석과 Slack 가격 비교를 건너뛰므로 실제 가격 추출만 빠르게 테스트할 수 있습니다.

## 설정

팝업에서 다음 정보를 입력합니다.

| 항목 | 설명 |
|---|---|
| 상품 상세 URL | 한 줄에 상품 URL 하나씩 입력합니다. |
| 애플리케이션 ID | 커머스API OAuth 토큰 발급에 사용합니다. |
| 애플리케이션 시크릿 | 커머스API OAuth 토큰 발급에 사용합니다. |
| 생성형AI 제공자 | Google Gemini 또는 OpenAI를 선택합니다. |
| 생성형AI API 키 | 상세페이지 이미지 가격 분석에 사용합니다. 비워두면 이미지 분석을 생략합니다. |
| Vision 모델 | Google은 Gemini 모델(권장 gemini-3.1-flash-lite), OpenAI는 Responses API 모델(기본 gpt-4o-mini)을 입력합니다. |
| Slack 경고 | Slack Bot 토큰과 채널을 입력하면 불일치 알림을 보냅니다. |
| 매일 자동 실행 | 지정한 시각에 검증합니다. Chrome이 실행 중이고 네이버 로그인 세션이 유효해야 합니다. |

입력값은 변경 즉시 자동 저장됩니다. 설정 내보내기는 URL을 JSON 배열로 저장하며, 불러올 때는 팝업의 줄바꿈 입력 형식으로 변환합니다.

## CSV 결과

검증 시작 시 실행 시간 기준 파일명을 정하고, 모든 상품 처리가 끝난 뒤 Chrome의 기본 다운로드 경로에 CSV를 저장합니다.

파일명 형식: yyyymmdd_HHMMSS.csv

열 순서:

1. 상품명
2. 상품 주소
3. 정상가
4. 할인가
5. 최대 할인가
6. 이미지 주소
7. 정상가(이미지)
8. 할인가(이미지)
9. 최대 할인가(이미지)

상품명·URL·이미지 주소 등 텍스트 열은 CSV 이스케이프를 위해 쌍따옴표로 감쌉니다. 6개 가격 열은 정수 또는 빈값으로 기록합니다. 이미지 주소는 가격을 찾은 이미지의 주소만 기록합니다.

## Slack 알림

이미지 가격이 실제 가격과 다르면 다음을 전송합니다.

- 상품명
- 실제 가격과 이미지 가격
- 상품 주소
- 이미지 주소
- 가격 이미지 미리보기

이미지에 최대 할인가가 있으면 최대 할인가끼리 비교합니다. 최대 할인가가 없으면 일반 할인가끼리 비교합니다.

## 설치

1. Chrome에서 chrome://extensions/를 엽니다.
2. 개발자 모드를 켭니다.
3. 압축해제된 확장 프로그램을 로드합니다를 선택합니다.
4. naver-price 폴더 또는 빌드된 dist/naver-price 폴더를 선택합니다.

## 빌드

저장소 루트에서 다음 명령을 실행합니다.

```bash
npm install
node build.js naver-price
```

빌드 결과는 dist/naver-price에 생성됩니다.

## 주의 사항

- 최대 할인가는 로그인 상태·보유 쿠폰·회원 혜택에 따라 달라질 수 있으므로 로그인된 상품 페이지의 표시값을 기준으로 합니다.
- 커머스API 권한이 없는 상품은 상세 이미지 분석을 할 수 없지만, 화면 가격 수집은 계속됩니다.
- 커머스API 시크릿, 생성형AI API 키, Slack Bot 토큰은 브라우저 로컬 저장소에 저장됩니다. 개인용 로컬 도구로 사용하고, 타인에게 배포하거나 운영 환경에서 사용할 때는 별도 서버에서 비밀정보를 관리하세요.
