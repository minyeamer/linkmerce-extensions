# coupang-ads

현재 버전: **v0.2.0**

쿠팡 Ads 탭을 새로고침하고 쿠키를 Slack에 텍스트 파일로 전송하는 Chrome Manifest V3 확장 프로그램입니다.

## 설치 및 사용

1. chrome://extensions/ 에서 개발자 모드를 켜고 **압축해제된 확장 프로그램을 로드합니다**로 이 폴더를 선택합니다.
2. https://advertising.coupang.com/ 에 로그인한 탭을 열어 둡니다. 여러 탭이 있으면 첫 번째 탭을 새로고침합니다.
3. 팝업에서 Slack Bot Token, Channel ID, 파일명(.txt 제외)을 입력합니다. 변경 사항은 자동 저장됩니다. Bot에 files:write, chat:write 권한을 부여하고 대상 채널에 초대합니다.
4. **추출 & 전송**으로 수동 실행하거나 **Slack 전송 스케줄**을 켭니다. 간격(기준 시각 포함) 또는 매일 지정 시각을 선택할 수 있습니다.
5. **새로고침 스케줄**은 Slack 전송 없이 세션 유지용 새로고침만 실행합니다.

naver-cookies와 동일한 수동 실행, 두 독립 스케줄, 다음 실행 시각, 실행 결과, JSON 설정 내보내기·불러오기를 지원합니다. 스케줄은 설치 시 기본적으로 꺼져 있으며 브라우저 재시작 시 복원됩니다. 시각은 브라우저의 로컬 시간대를 따릅니다. Chrome이 실행 중이어야 하며 절전 상태에서는 실행이 지연될 수 있습니다.

전송 및 새로고침 간격 모드의 기준 시각(`baseTime`)은 `HH:MM:SS` 형식(예: `08:00:30`)으로 초까지 설정할 수 있습니다. 기존 `HH:MM` 설정은 초를 `00`으로 처리합니다. 반복 간격은 분 단위를 유지하며, Chrome의 알람은 브라우저 상태에 따라 예약 시각보다 늦게 실행될 수 있습니다.

## 쿠키 범위와 전송

- advertising.coupang.com에 적용되는 서비스 쿠키와 공통 부모 도메인 쿠키(예: .coupang.com)를 수집합니다. 다른 쿠팡 서비스 전용 쿠키는 제외합니다.
- 같은 이름은 서비스 전용 도메인과 긴 경로를 우선하여 하나만 남기고 이름순으로 정렬합니다. 파일 형식은 name=value; name2=value2 입니다.
- 탭이 없거나 새로고침 실패·시간 초과 또는 쿠키가 없으면 전송을 중단하고 오류를 기록합니다.
- 새로고침 후 로그인 페이지라면 `a[href^="/user/login?_cap_client=WING"]` 링크를 한 번 클릭하여 Wing의 기존 로그인 세션으로 자동 로그인합니다. Wing에 로그인된 상태여야 합니다.
- 수동 실행 및 두 스케줄 모두 같은 로그인 확인 과정을 거칩니다. 로그인 후 Ads의 `/marketing/` 화면으로 돌아온 것을 확인한 뒤 쿠키를 전송합니다.
- 화면 제목 또는 본문에 Access Denied가 있거나 로그인 페이지에 Wing 로그인 버튼이 없으면 로그인 및 쿠키 전송 없이 종료하고 다음 새로고침을 기다립니다. 로그인 URL을 직접 열거나 다른 로그인 버튼을 클릭하지 않습니다.
- 자동 로그인 확인은 최대 30초 동안 기다리며, 완료하지 못하면 오류를 기록합니다. 동시에 요청된 새로고침은 하나의 작업으로 실행하여 중복 로그인을 방지합니다.
- 네이버 전용 NID_SES 검사는 사용하지 않습니다. 로그인 확인은 페이지 경로, 내용, 로그인 링크를 기준으로 하며 서버 API로 인증 유효성을 검사하지 않습니다.
- Slack Files API의 getUploadURLExternal → 업로드 → completeUploadExternal 순서를 사용합니다.

설정은 확장 프로그램별 로컬 저장소에 보관됩니다. 내보낸 JSON에는 Slack 토큰이 포함되며, 업로드한 쿠키 파일에는 인증 정보가 포함될 수 있으므로 접근 권한을 관리하세요.

## 빌드

저장소 루트에서 다음 명령을 실행합니다.

```powershell
node build.js coupang-ads
```

결과는 dist/coupang-ads/ 에 생성됩니다.

## 권한

cookies(쿠키 읽기), tabs(대상 탭 조회·새로고침), alarms(스케줄), storage(설정·결과 저장)를 사용합니다. Ads 전용 content.js가 로그인 화면 확인과 Wing 로그인 링크 클릭을 담당합니다. 호스트 권한은 advertising.coupang.com, slack.com, files.slack.com으로 제한합니다.
