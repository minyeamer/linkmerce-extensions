## 변경 및 코드 검증

v3.5.2는 첫 목록 페이지에서 요청 헤더를 얻고 같은 탭 안에서 목록 API를 페이지별로 조회한다. 페이지 버튼 클릭에 의존하지 않는다. 실패 페이지는 최대 4회 시도하며, 프록시가 있으면 재시도 전 IP를 바꾸고 첫 페이지를 다시 열어 요청 값을 갱신한다. 페이지별 상품 수와 최종 주소 수를 검증하고, 계속 실패해도 앞선 페이지의 주소와 명시적인 판매처 오류를 함께 보존한다.

`tests/naver-products-stores.cjs --built`는 원본 및 난독화 빌드의 목록 API 스크립트와 수집 실행 코드를 모의 Chrome/HTTP 응답으로 검증한다. 정상 다중 페이지, 429 후 복구, 요청 값 갱신, IP 교체, 4회 제한, 부분 결과 보존, 반복 페이지, 총 개수 변경, 중단과 탭 정리를 확인했다.

실제 사이트 확인은 Chrome 페이지 조작으로 진행했다. 새 빌드를 Chrome 확장 프로그램으로 재로드하여 실제 HTTP 응답으로 수집하는 실행은 이 도구 환경에서 검증하지 못했다. 따라서 실제 페이지 확인과 모의 응답 코드 검증을 구분해야 한다.
